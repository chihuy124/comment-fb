🧩 Chrome Extension (bắt buộc để cào Reels)

Công cụ cào Reels chạy hoàn toàn qua Chrome Extension, dùng chính session Facebook bạn đang đăng nhập — không cần dán Cookie, không cần server.

Cài đặt: mở chrome://extensions → bật Developer mode → Load unpacked → chọn thư mục extension/.
Sau mỗi lần cập nhật extension: bấm 🔄 reload ở trang extensions, rồi hard-reload trang này (Cmd/Ctrl + Shift + R).

Cấu hình số tab song song và timeout: bấm vào icon extension trên thanh công cụ Chrome.
